# Demo 分镜脚本（60 秒 · 待真机拍摄）

> v1.0 ｜ 2026-09-19 ｜ 拍摄者照此分镜执行；素材要求与检查单见文末。
> 目标：让不懂技术的老板在 60 秒内看到「甩包 → 自装配 → 微信收到汇报」的全过程。

## 分镜（总长 60s）

| # | 时长 | 镜头 | 操作（屏幕内容） | 字幕/旁白 |
|---|---|---|---|---|
| 1 | 0-5s | 全屏·Desktop 空白会话 | 一台刚装好的 Hermes，无任何定制 | 「一台全新的、谁都不认识的 AI agent」 |
| 2 | 5-12s | 全屏·文件管理器 | 把 `02-交付包/hermes/` 文件夹拖到桌面，对 agent 说：「读取 交付包/00-自装配指令.md，按指令执行」 | 「我们只做一件事：把施工图给它」 |
| 3 | 12-30s | 全屏·聊天流（可 2-4 倍速） | agent 依次执行：写 SOUL → 落位 AGENTS → 装技能 → 建工作流；每步前的验证动作完整出现 | 「它自己装自己：人格、约定、技能、工作流」 |
| 4 | 30-40s | 分屏·左聊天右微信 | agent 发出装配完成报告（装了什么/验证结果/留给主人的三件事） | 「干完还交报告」 |
| 5 | 40-52s | 手机竖屏实拍 | 第二天早上 7:30，微信弹出晨间汇报（首行声明+三栏内容） | 「第二天早上，它开始上班了」 |
| 6 | 52-60s | 尾帧 | 仓库门面 banner + slogan「客户的数据只住在客户电脑里」+ GitHub 地址 | 「MIT 开源 · ai-landing-consultant」 |

## 拍摄要求

- 分辨率 ≥1080p，屏幕缩放 100%（否则字太小）；字体缩放提前调大（Windows 显示设置 125% 亦可）
- **脱敏红线**：入镜的测试数据全部用虚构内容（「云溪科技」「王女士」级）；录制前关掉微信其他聊天窗口； 成片检查单见 launch 文案
- 时长红线：成片 ≤60s（社交平台完播率）；第 3 镜加速不剪验证动作——验证动作是本项目的卖点

## 发布出口（拍完即用）
