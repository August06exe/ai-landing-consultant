## 中文版 A（即刻/V2EX「分享创造」风 · 342 字）

> 开源了一个东西：AI 落地顾问——帮完全不懂技术的人，装上一台真正每天在干活的 AI agent。
>
> 这半年帮人装 agent 装出一个体会：技术玩家缺的不是框架，是「落地」这件事本身没人管——需求聊不清、工作流没人设计、出了问题没人接。所以我把顾问的活儿做成了开源系统：11 道标准工序（访谈→方案→交付包→部署→验收→陪跑），每道带验收标尺。
>
> 最不一样的是交付方式：部署只做到「agent 活了+模型通了」，然后把交付包甩给那台空白 agent——它自己读包、装人格、建工作流、配定时任务，装完交报告。客户全程不用碰命令行。
>
> 内含：顾问提示词、财务/投资/数据/法务四套合规红线技能包、六个完整虚构案例（拉面店/会计所/个人投资者/诊所/评价管家/征期提醒官，含 L1-L3 三种服务包形态）、13 份落地专题（含微信 iLink 的坑）。
>
> 一句话：客户的数据只住在客户电脑里，开源的是产线，不是客户档案。MIT，拿去用，拿去赚钱。
> GitHub 搜 ai-landing-consultant。

## English A（Reddit r/LocalLLaMA / r/SideProject 风 · 约 300 词）

> I open-sourced the missing role in self-hosted AI: the **landing consultant**.
>
> After deploying agents for non-technical folks, the pattern became obvious — these people don't need another framework. They need someone to interview them, design the workflows, deliver the thing, and answer the phone when it breaks. So I turned that consultant role into an open-source system: **11 standard operating procedures** (interview → solution → delivery package → deploy → acceptance → companion service), each with acceptance checklists.
>
> The unusual part is the delivery pattern: you only deploy until "the agent is alive and the first model answers." Then you hand over a **delivery package**, and the fresh agent assembles *itself* — writes its persona, places its task conventions, installs skills, builds workflows (a daily heartbeat first), sets up cron jobs, and files a completion report. The end user never touches a command line.
>
> Inside: the consultant prompt, four domain skill packs with compliance red lines (finance / investment / data / legal — "place the trade for me" gets a refusal plus escalation, never compliance), six complete sample cases (ramen shop, accounting firm, individual investor, dental clinic, review butler, tax-deadline alarm — L1 through L3), and 13 field guides — including a documented "out of the box" path: download → model connected → channel connected → first scheduled job, six steps, zero mandatory terminal.
>
> Everything runs self-hosted: your client's data never leaves their machine. We open-source the production line — never the client files. MIT — take it, sell with it.

## English B（Show HN 风 · 标题+首评建议）

**标题**：Show HN: AI Landing Consultant – open-source playbook for deploying AI agents to non-technical users

**首评**：Hi HN! We built this after noticing that self-hosted agent adoption fails at the "last mile" — not installation, but everything around it: requirements, workflow design, acceptance, and someone to call when it breaks. The repo packages that last mile as 11 SOPs executed by an AI consultant, plus a self-assembly delivery pattern: the agent reads the package and builds itself. Four fictional-but-complete sample cases show the whole flow per industry, each with its own compliance red lines (finance/legal/medical variations). Methodology is platform-agnostic; current implementation targets Hermes Agent because of its native messaging-channel support. Happy to answer questions about the self-assembly pattern and the guardrails design.
