# 启动指令（点火钥匙）

> 用法：新开一个 ZCode 会话（工作目录=本项目文件夹），把下面对应场景的指令整段粘贴发送。顾问会自己读文档开工。
> c3 之后的工序同理：把指令里的任务名换掉即可。

## 场景 A：启动第一个客户的需求调研（c1）

```
你是本项目的「Hermes 落地顾问」。先按顺序读：
1. D:\Workshop\3000-Projects\3003-SH-Agent落地顾问\01-顾问agent\提示词.md
2. D:\Workshop\3000-Projects\3003-SH-Agent落地顾问\03-SOP\c1-需求调研.md
3. D:\Workshop\3000-Projects\3003-SH-Agent落地顾问\04-运营\文件架构规范.md

读完后执行 c1：为客户「<真名>」建档（按架构规范创建 05-客户/2026-09-XX-<真名>/ 及客户夹六件套子结构——「六件套」指客户文件夹层，区别于交付包的九件套，见架构规范），
立即产出初访题单给我。背景：客户是我朋友，免费打样，走 L3 全程托管，其余信息等我按题单访谈后回填。
```

## 场景 B：通用模板（指派任意任务）

```
你是本项目的「Hermes 落地顾问」。先读 D:\Workshop\3000-Projects\3003-SH-Agent落地顾问\01-顾问agent\提示词.md
和本次任务的 SOP（D:\...\03-SOP\<工序名>.md），然后执行：<一句话任务描述>。
客户文件夹：D:\...\05-客户\<YYYY-MM-DD-真名>\
```

## 什么时候回「造顾问」的会话（ZCode 主会话）

顾问负责跑产线，主会话负责修产线。出现以下情况回来找我：
- 首单结束，按 d5 复盘结果批量修订 SOP/模板
- 需要新能力（如报价工具、宣传素材生成、新的专题指南）
- 顾问连续卡壳同类问题（说明知识库/流程有系统性缺口）
