# deep-search（顾问版深度调研）

深度档可选用完整管线 `../deep-research/SKILL.md`（SCOPE→PLAN→RETRIEVE→TRIANGULATE→SYNTHESIZE→CRITIQUE→PACKAGE，证据库+引用校验）。**该管线无许可证、不随本仓库分发**——没有它时，深度档按下表「深度」行的方法自行组织多轮检索与综合，质量线不变。

## 何时用哪档

| 档位 | 场景 | 做法 |
|---|---|---|
| 轻查 | 单一事实（某命令参数、某平台是否支持） | grep `02-知识库/02-官方文档/llms-full.txt` 或 1-2 次搜索，直接回答 |
| 标准 | 网关对比、方案选型、给客户的专题说明 | 本技能：3-6 个来源，结论+引用清单 |
| 深度 | 新业务方向、竞品与定价、给老板的决策报告 | 走完整 deep-research 管线（evidence.jsonl 落盘） |

## 顾问专用规则

1. **知识库优先**：凡 Hermes 相关问题，先 grep `02-知识库/02-官方文档/llms-full.txt`（查法见 `02-知识库/README.md`）。官方文档是最高优先级来源，行号即可作引用。
2. **来源随行**：每条事实性结论后附 `[来源: URL 或 llms-full.txt:行号, 日期]`。
3. **产出位置**：为客户做的调研 → `05-客户/<客户>/调研/` 或直接进 `02-交付包/`；为项目做的 → `02-知识库/01-专题/` 或 `02-知识库/调研-*.md`。
4. **回填义务**：调研中发现「知识库没有且未来会再用」的事实，回填知识库并在索引登记。
5. 中文交付；引用可保留英文原文，结论必须中文。
6. 时效敏感数据（价格、版本号、Star 数、排名）一律标注查询日期。

## 质量线

- 给老板拍板用的结论：≥2 个独立来源。
- 来源冲突不藏：并列列出冲突点，给出你的判断与理由。
- 不编造 URL；未亲自验证的链接标「未验证」。
- 每份调研报告末尾附「局限性」：没查到什么、哪些结论可能过期。
