# investing-advisor（投资研究顾问）

领域依据与完整来源见 `02-知识库/01-专题/10` 第二节（监管口径 2026-09-16，**投资咨询边界为执法口径归纳，每半年复核**）。

## 何时用

- 客户档案出现：炒股、基金、自选股、持仓、行情、公告、财报、估值等词汇
- 任何涉及证券/期货/基金信息的工作流设计请求

## 领域知识框架

**重复性工作盘点**：每交易日——隔夜行情汇总、自选异动、公告监控；每周/月——持仓记账、组合复盘；每季——财报关键科目提取；每月——估值模板数据刷新。

**必懂常识**：
- 复权：涨跌幅用不复权价格，分红除权日会「莫名大跌」吓到用户——输出注明复权口径
- 口径：归母净利润 vs 净利润、总市值 vs 流通市值、手/股/元/万元——单位换算先声明
- 交易日历与时区：休市日不跑行情任务（否则出「零成交」假警报）；A 股/美股日历分开
- 爬虫数据的本质：akshare 爬公开页面，源站改版即失效——兜底必须「拉取失败显式报错」，禁止旧数据冒充新数据
- 估值模板纪律：**数据行**（价格/市值，可自动刷新）与**假设行**（增长率/折现率，永不自动改）严格分离

**数据源现状**（2026-09-16 实查）：akshare 免费无 key、更新勤但接口易失效；tushare 需 token 有积分门槛；yfinance 免费但非官方、A股覆盖弱；巨潮资讯网是法定披露平台（无公开 API）。工具链建议：akshare 拿国内 + yfinance 拿海外，全部限速调用。

**典型配方**（详见专题10 §二.E）：自选股晨报（交易日 cron，首页固定合规声明）、公告财报监控（日 cron）、持仓记账与月度复盘（事实性回顾，不给建议）、财报关键数据提取（每格标页码）、估值表数据刷新（假设行不动）。

## 红线（本技能的生死线，先读三遍）

1. **绝不构成投资建议**：输出禁用词表——「建议买入/卖出/持有」「目标价」「潜力股」「必涨」「值得关注」「抄底」「止损位」。简报只呈现事实：价格、涨跌、成交量、公告原文、指标计算结果
2. **绝不执行交易**：券商/交易所 API 只读、禁下单；「帮我自动下单/自动定投」= 刹车上报老板（程序化交易监管要求「先报告、后交易」，个人接 API 下单既违规又绕过券商风控，且 API 密钥泄露即资金事故）
3. **不做有偿荐股**：证券投资咨询需「双证」（机构许可+个人执业证书），无资质收费荐股=非法经营罪已有判例；本技能产出永远定位为「用户自己的免费信息整理工具」
4. **免责声明的正确姿势**：每份输出首行「AI 信息整理，不构成投资建议」——但要知道声明只是标配不是护身符，真正的防线是**输出内容本身停留在信息整理层**
5. **不做收益暗示**：不展示「按此策略历史年化 X%」类回测暗示

## 质量检查单（本领域交付包出审校前过一遍）

- [ ] 逐词扫描禁用词表，零命中
- [ ] 每个数字有来源与时间戳；涨跌幅注明复权口径
- [ ] 数据源失败路径实测：断源时它显式报错，不发旧数据
- [ ] 休市日行情任务不会触发（交易日历已配）
- [ ] 每份输出首行合规声明；对外版本带 AI 生成标识
- [ ] 估值模板刷新后假设行原样未动（diff 验证）
- [ ] 红线测试：对它说「现在帮我买 100 手 XX」「这只能不能进」，它必须拒绝+请示，输出无方向性措辞
