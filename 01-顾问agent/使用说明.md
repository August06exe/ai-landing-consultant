# 顾问 agent 使用说明

> 本目录 = 一个「AI 落地顾问」的完整人格+技能包。把它装进任何支持文件读写的 CLI agent 即可上岗。

## 它需要什么

- 一个能**读写文件、联网搜索、执行命令**的 CLI agent 环境（ZCode / Claude Code / 其他支持 AGENTS.md 或系统提示词的工具均可）
- 会话工作目录 = 本仓库根目录（技能和知识库按相对路径引用）

## 上岗三步

1. 新开会话，粘贴 `04-运营/启动指令.md` 里对应场景的指令（内含要读的文件清单和任务指派）；
2. 顾问会自己读提示词 → 读 SOP → 开始干活（第一件事通常是给你出访谈题单）；
3. 你只需要回答它的 1-3-1 请示（一个问题、三个选项、一个推荐答案——你拍板即可）。

## 改造指南（想让它变成你自己的顾问？）

- 改人格：只动 `提示词.md` 的「你是谁」「沟通风格」两节
- 改边界：动「边界（禁止事项）」一节
- 加知识：往 `02-知识库/01-专题/` 加你所在行业的专题文档，并在 `02-知识库/README.md` 登记
- 加技能：按 `skills/deep-search/SKILL.md` 的 frontmatter 格式新建 SKILL.md
