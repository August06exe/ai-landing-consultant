## 技術がわからない人に、専属 AI エージェントを

これは新しい agent フレームワークではありません。**「導入コンサルタント」という役割そのもののオープンソース版**です。

自ホスト型 AI agent は、技術者にはおもちゃですが、普通の人には壁です。このリポジトリは、ベテランコンサルタントの仕事——**ヒアリング、要件定義、納品パッケージ作成、検収、伴走サポート**——を 11 の標準プロセス（SOP）に分解し、AI コンサルタントが実行できるようにしました。

その結果、ラーメン店の店主でも、小さな経理事務所でも、**自分専用の AI エージェント**が手に入ります。業態に合わせた人格、毎日使っているチャットアプリとの接続、毎日自動で回るワークフロー、そしてガードレール内での自己進化。

## 3 つの特長

1. **データは手元から出ない** — セルフホスト。エージェントはお客様の PC で動き、チャット履歴も業務データも third-party に送られません。オープンソースなのは「生産ライン」であって、クライアントのファイルではありません。
2. **再現できる納品** — 11 の標準プロセス、各プロセスに品質チェックリスト付き。サービスはインスピレーションではなく、仕組みとして複製できます。
3. **セルフアセンブル方式** — 納品パッケージはマニュアルではなく「施工図」。空の agent が自分でパッケージを読み、人格・ワークフロー・定期タスクを自分で組み立て、完了報告を提出します。
