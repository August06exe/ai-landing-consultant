# d2-故障分诊（三级 · 谁处理什么）

> 版本 1.0 ｜ 三方协同 ｜ 原则：能自愈不自扰，能远程不上门

## L1 客户自检（发使用卡截图即可，1 分钟）

1. Desktop 开着吗 / 重开一次
2. 电脑重启过吗（多数「没消息」=网关没起来，自启会拉）
3. 微信扫码登录过期 → 重新扫（发「扫码重连」教程截图）
4. 还不行 → 截图报错原文 + 一句话说明在哪一步，发给老板

## L2 老板处理（5 分钟内能做的）

- 网关没跑：启动 `hermes gateway`
- 渠道掉线：重新扫码 / 重启网关
- 更新报错：查 `02-02-知识库/01-专题/04`「更新三大守卫」（关 Desktop 再更新）
- 处理完让客户再发一条消息确认恢复

## L3 顾问处理（老板转后台会话）

- 拉日志定位、查官方文档、给出操作步骤让老板执行
- 涉及账号风控/平台侧问题 → 顾问给判断，老板与客户沟通
- 每次处理完，**三行写进 03-陪跑日志**：症状 / 根因 / 解法

## 常见病速查（详见 `02-02-知识库/01-专题/04` 路由表）

| 症状 | 第一嫌疑 |
|---|---|
| 渠道没消息 | 网关没跑 / 扫码过期 |
| 「它变笨了」 | 上下文压缩 / 模型被切 / 辅助槽指错 |
| cron 没触发 | 网关死了（cron 寄生在网关） |
| 更新失败 | Windows 进程锁守卫 |

> 纪律：同一问题出现 ≥2 次 → 顾问当天升级为知识库条目 + 使用卡/自装配指令模板修订。
