# d4-进化守护（月度体检：自写技能/记忆/成本/cron）

> 版本 1.0 ｜ 主责：顾问分析，老板执行 ｜ 频率：每月一次（L3 陪跑含 1 次；续费可含）
> 背景：Hermes 会自己写技能、攒记忆——这是它的卖点，也是失控风险点。守护=让它进化得安全。

## 体检四项

### 1. 自写技能审查
让它列出自己新写的技能（或查 skills 目录变化），顾问逐个看：
- 干什么的、写得好不好、有没有重复造轮子
- **安全**：有没有碰禁区（支付/删除/外发数据）
- 处置：好的保留并表扬（正反馈）、差的删、越界的删+进 化守则 强调

### 2. 记忆体检
抽查它记住了什么：有没有积累错误偏好（把口误当指令、记住过期信息）。
清理：让它自己总结「你对我主人的理解」，错了纠正，陈旧的记忆刷新。

### 3. 成本复查
Desktop 仪表盘看月 token 用量与模型分布：
- 异常高 → 查哪条工作流烧的（长上下文/高频 cron），降频或压缩
- 辅助槽还是 auto 且主模型贵 → 指到便宜档（02-02-知识库/01-专题/03）

### 4. cron 与工作流健康
- 有没有客户从来不用的 cron → 建议停掉（省 token 不添乱）
- 失败过的 cron → 修或删

## 产出

**月报**发到客户微信（可让 Hermes 写初稿、老板发）：本月它干了多少活/学会了什么/花了多少钱/下月建议。月报同时是**续费触点**——价值可见，续费才顺。
