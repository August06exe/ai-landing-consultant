# c2-方案设计（选型与拍板）

> 版本 2.2 ｜ 主责：顾问，老板拍板 ｜ 前置：c1 定稿 ｜ 产出：方案定稿（进交付包素材）
> v2 依据：`02-知识库/01-专题/08`——成本失控是最快见血的流失导火索（默认贵模型档没人改、技能死循环烧 token，爆雷都在头几天）；静默故障是长期留存第一杀手，方案阶段就要埋「心跳」防线。

## 输入

01-档案与需求.md（定稿）：客户水平、设备网络、入口偏好、付费方式、工作流清单+验收场景、月度费用预期上限。

## 步骤

### 1. 选模型（查 `02-知识库/01-专题/03` 决策树）
按「网络条件 × 付费方式 × 数据敏感度」四选一：Nous Portal / OpenRouter / Custom端点（国内现实解：GLM/DeepSeek）/ 本地。
顺手定**辅助槽策略**（压缩/摘要/审批指便宜档），这是给客户降本第一杠杆——行业证据：多模型路由可省约 80% 账单，不路由的家庭用户就是全价买单。
→ 有分叉用 1-3-1 给老板拍板。

### 2. 选网关（查 `02-知识库/01-专题/01` 决策表）
按客户身份（个人/企业）× 需求（双向对话/定时推送/群）选渠道。微信注意 iLink 群聊限制要提前说死。cron 推送目标=对应渠道 home channel。
**入口纪律**（v2）：入口跟着客户现有习惯走（微信就用微信），绝不让客户为一个 agent 学新 App。

### 3. 技能配装（查 `02-知识库/01-专题/05` 纪律）
技能跟工作流走：每条工作流列出依赖技能；没用的不装；安全/支付类不给小白。
**外部内容=敌意**（v2，普适纪律，不只高危客户）：凡替客户收外部信息（邮件/网页/群消息）的工作流，方案里就定为**草稿模式**（只进草稿/只出建议，不直接外发）；外发类操作一律人工确认。

### 4. 工作流定稿
每条按六要素搭骨架（触发/输入输出/分步SOP/失败兜底/验收场景/版本头），标注：
- 依赖：需要什么工具权限、什么技能、什么外部账号
- 成本：预估月 token 量级（给老板定价参考）
- **自动化程度**：全自动 / 需确认（判断与执行类必须人审，参照 `02-知识库/01-专题/10` 分层）

**心跳工作流必选**（v2，硬规则）：无论客户要什么，方案里永远包含一条**每日晨间活儿汇报**（固定时间发一句「今天我会做：…」+昨日完成情况）。它同时是：存在感装置（客户每天确认它活着）、失联报警传感器（连续 24h 没收到=d2 速查第一行）、价值展示位（日报必带「本周已帮你完成 N 件」计数，供 d3 排队/d4 月报/d5 复盘使用）。
**心跳双报**（v2.2，硬规则）：心跳日报**同时抄送老板渠道**（老板微信收到同一条或仅通知行）——这是 d2 L0 失联巡逻的探测手段：老板没在约定时间收到抄送=心跳可能死了，立即按 d2 L0 开诊。方案里必须写明老板的抄送渠道（微信备注号即可）。

### 5. 成本护栏（v2 新增；v2.2 对齐官方文档口径，给 c4/c6 用）
- 官方**无原生「月度 token 硬顶」配置**（见 c4 v2.1 注）——护栏是组合拳，方案里写清四件：①**月度费用上限数字**（主口径，provider 侧/代理侧止停）②辅助槽降档策略（压缩/摘要/审批指便宜档，见步骤 1）③守则约束（进交付包进化守则）④**人工巡检排期**（头 7 天每天看 dashboard；之后 d3 周反馈+每月 d4 体检各看一次——巡检点写进 `04-运营/陪跑排程器.md`）
- 默认模型档**锁定**并写明「客户不得自行切贵模型」（进使用卡）
- 交付后头 7 天为成本观察期：老板每天看一眼用量（行业证据：爆雷集中在头几天）

### 6. 安全基线（给 c4 用）
allowed_users、审批模式、禁区清单（客户档案 §5 + 通用底线：支付/删除/外发类操作必须人工确认）+ v2 的外部内容敌意纪律落为逐条工作流的草稿/确认标注。

## 产出与流转

方案定稿 → 老板确认（含成本测算与护栏参数）→ 流转 c3 制作交付包。

## 红线

- 所有命令/配置以官方文档核实为准，不确定标「未验证」。
- 方案里的每条工作流必须有验收场景，没有就退回 c1 补。
- 方案里没有心跳工作流 = 不合格方案，不得流转 c3。
- 专业领域客户（财务/投资/数据/法务）：先加载对应领域顾问技能（`01-顾问agent/skills/`），红线进方案。

## 质量标尺（做完这道工序，逐条打勾才算完）

- [ ] 模型/网关/技能三选型都有知识库依据，分叉走了 1-3-1
- [ ] 辅助槽策略已定（不是 auto 糊弄）
- [ ] 每条工作流：六要素齐 + 自动化程度标注 + 成本量级
- [ ] 心跳工作流在清单里：定义了失联判定标准（连续 24h 无消息）+ **双报抄送渠道** + 「本周完成 N 件」计数器
- [ ] 收外部信息的工作流全部标注「草稿模式」，外发类全部「人工确认」
- [ ] 成本护栏四件（费用上限/辅助槽/守则约束/巡检排期）已写死，与 c4 v2.1 口径一致
- [ ] 安全基线覆盖 allowed_users/审批模式/禁区清单三件
