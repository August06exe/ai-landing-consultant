# c4-部署引导（UU远程 · 通模型 · 甩包）

> 版本 1.0 ｜ 主责：老板（顾问提供执行单与技术支持）｜ 前置：c3 交付包审校通过
> 目标底线只有一条：**Hermes 活了 + 第一个模型通了 + 安全基线设好**，剩下全交给自装配。

## 准备

- [ ] 约时间：客户电脑前，30-60 分钟，双方网络通畅
- [ ] 工具：UU 远程（或 ToDesk/向日葵备用）、官方 Desktop 安装包已下载到本地
- [ ] **开录屏**（存 00-商务：留证+复盘+素材）
- [ ] 交付包已传到自己手机/网盘（随时可放进客户机）

## 步骤

1. **环境快检**（2 分钟）：GitHub 与模型 API 可达性（不行先解决网络，装不上十有八九是这个）
2. **装 Desktop**：官网安装包，下一步到底，免管理员权限
3. **通第一个模型**：`hermes setup`（或 Desktop 内引导）按 c2 选型接通，发一句测试话确认有回应
4. **安全基线**：设 allowed_users（只允许客户自己）、审批模式按 c2、确认支付/安全类技能未装
5. **甩包**：把 `02-交付包/hermes/` 放到客户机固定位置（如 `~/交付包/`）
6. **触发自装配**：对 Hermes 说：「读取 `交付包/00-自装配指令.md`，按指令执行，完成后给我完成报告」
7. 进入 c5 盯装配；期间向客户讲 02-使用卡的三件事

## 回退

- 网络不通 → 手机热点试；再不行改约，别硬耗
- 安装/模型卡死 → 查 `02-02-知识库/01-专题/02` 自查清单；10 分钟无解就改期，问02-知识库/顾问

## 完成标志

自装配完成报告全绿 → 进 c5 逐项核对。
