# c4-部署引导（UU远程 · 通模型 · 甩包）

> 版本 2.1 ｜ 主责：老板（顾问提供执行单与技术支持）｜ 前置：c3 交付包审校通过
> 目标底线只有一条：**Hermes 活了 + 第一个模型通了 + 安全基线设好**，剩下全交给自装配。
> v2 依据：`02-知识库/01-专题/08`——渠道侧信任脆弱（一次隐私舆情即动摇用户）；成本爆雷集中在交付后头几天，护栏要在部署当天就生效。

## 准备

- [ ] 约时间：客户电脑前，30-60 分钟，双方网络通畅
- [ ] 工具：UU 远程（或 ToDesk/向日葵备用）、官方 Desktop 安装包已下载到本地
- [ ] **开录屏前先做知情同意**（v2 新增，一句话即可）：「全程录屏用于留证和复盘，只我们自己看；如果做宣传素材会先征得你同意并脱敏。」客户点头再录——渠道信任脆弱，主动透明是最好的疫苗
- [ ] 交付包已传到自己手机/网盘（随时可放进客户机）

## 步骤

1. **环境快检**（2 分钟）：GitHub 与模型 API 可达性（不行先解决网络，装不上十有八九是这个）；顺手查杀毒软件类型（Windows Defender/第三方——已知墙位见 `02-知识库/01-专题/02`「杀软墙位」节）
2. **装 Desktop**：官网安装包，下一步到底，免管理员权限
3. **通第一个模型**：`hermes setup`（或 Desktop 内引导）按 c2 选型接通，发一句测试话确认有回应
4. **安全基线**：设渠道白名单（各平台 `allowed_users`，只允许客户自己）、审批模式按 c2、确认支付/安全类技能未装、Desktop 状态栏 YOLO 关闭
5. **成本护栏生效**（v2 新增；v2.1 按官方文档校正表述）：官方**无原生「月度 token 硬顶」配置**——护栏是组合拳：①dashboard Usage analytics 打开给客户看（用量可见）；②辅助槽（压缩/标题/审批）按专题03 配便宜模型降档；③`agent` 进化守则写死「不自行动长任务/高频任务」；④d4 月度体检跑用量巡检（cron 查 `/usage` 类数据+仪表盘核对）——头 7 天是成本观察期，从今天开始算
6. **甩包**：把 `02-交付包/hermes/` 放到客户机固定位置（如 `~/交付包/`）
7. **触发自装配**：对 Hermes 说：「读取 `交付包/00-自装配指令.md`，按指令执行，完成后给我完成报告」
8. 进入 c5 盯装配；期间向客户讲 02-使用卡的三件事（含期望管理一句话）

## 回退

- 网络不通 → 手机热点试；再不行改约，别硬耗
- 安装/模型卡死 → 查 `02-知识库/01-专题/02` 自查清单；10 分钟无解就改期，问 02-知识库/顾问

## 完成标志

自装配完成报告全绿（首项=心跳工作流已建）→ 进 c5 逐项核对。

## 质量标尺（做完这道工序，逐条打勾才算完）

- [ ] 录屏知情同意已做并录在案
- [ ] 环境快检两项（GitHub/API）有结论，杀软类型已记录
- [ ] 第一个模型有真实对话回应（截图存证）
- [ ] 渠道白名单/审批模式/禁区三件已设，支付安全类技能为零，YOLO 关闭
- [ ] 成本组合护栏已生效（用量可见+辅助槽降档+守则约束），7 天观察期开始
- [ ] 自装配已触发且完成报告全绿，心跳工作流排第一已建
- [ ] 客户当场用过一次使用卡口令（哪怕只是打招呼）
