# c1-需求调研（三轮访谈制）

> 版本 2.0 ｜ 主责：老板访谈，顾问加工 ｜ 产出：01-档案与需求.md 定稿
> 原则：**方案没确认不开工**；事实顾问自己查，决策客户拍板。
> v2 依据：`02-知识库/01-专题/08` 落地痛点调研——「做出来没人用」是最致命失败（MIT 95% 试点零回报，根因是学习差距而非模型）；期望管理失败与冷启动选型错误是两大可预防根因。

## 第一轮·初访（老板 × 客户，30-60 分钟）

**顾问的事（访谈前）**：出「初访题单」给老板，覆盖：
1. 业务背景：做什么的、服务谁、一天/一周的节奏
2. **重复劳动清单**：每天/每周固定花时间的事，逐条问（这是工作流的原料，追问到能举例）——**含土办法**：现在用纸笔/Excel/备忘录凑合做的事必问，这是冷启动选型的金矿（客户已经在做的行为，才最可能持续用起来）
3. 现有工具：手机电脑用什么、微信还是飞书、有没有用过 AI
4. 设备网络：电脑配置、能否访问 GitHub/国外 API（现场能测就测）
5. 意愿：预算感觉、模型费谁出、最想要的一个场景、最不让碰的禁区
6. 时间价值（一句话就够，供 d4 价值量化用）：「你一个小时的时间大概值多少钱？」——答不上来就用当地最低时薪×3 兜底
7. **期望探底**（v2 新增）：「你希望它替你做什么**决定**？」——若客户期望 agent 替他做判断/承诺结果，当场校准（见第二轮期望管理三句话）；「如果它偶尔出错，你能接受怎么样的出错方式？」——为审批模式与草稿策略取证

**老板的事**：按题单聊，多要具体例子（「上礼拜你有没有遇到过…」），不聊技术细节。
**访谈后**：记录进 `01-档案与需求.md` §1-2（允许原话、允许残缺）。

## 中间轮·顾问加工

1. 顾问读档案 → 缺口走 grilling 追问老板（不追问客户）。
2. 顾问必要时做**限时业务简报**（L2 以上：≤1 小时、1 页、进 04-调研）。
3. 产出**初步方案 + 可能性工作流清单**：每条工作流一句话说清「做什么+多久用一次+省多少事+大约多难」，按 ROI 排序，标出建议砍掉的；**每条标注自动化程度**（全自动 / 半自动需确认 / 仅提醒），依据 `02-知识库/01-专题/10` 的分层原则：整理与监控可全自动，判断与执行必须人审。
4. **冷启动选型纪律**（v2 新增，硬规则）：建议客户**第一条**上线的，必须来自客户**已经在做**的重复行为（哪怕纸笔在做）；「听起来很酷」的新场景一律排后。上线首周的唯一目标=客户独立成功使用一次最常用工作流——这条纪律写进方案，老板与客户都要知道。
5. 老板消化并挑选，定第二轮要谈的版本。

## 第二轮·方案确认（老板 × 客户）

1. 老板用客户语言过每条工作流（不谈实现，谈「你会得到什么」）。
2. **期望管理三句话**（v2 新增，第二轮必说，记录客户确认）：
   - 「它是实习生，不是员工：会出错、需要教，越用越顺手」
   - 「简单任务它很稳；越复杂的任务越需要你过目确认」
   - 「它整理信息，**不替你做决定**；要花钱/对外/删东西的事，一定先问你」
3. 逐条确认：**要做 / 不做 / 以后做**；每条「要做」的当场说定**验收演示场景**（客户认可的、能当场复现的例子）；专业领域（财务/投资/数据/法务）的工作流，验收场景里**加一条红线测试**（客户说一句越界请求，看它会不会拒绝——依据 `02-知识库/01-专题/10`）。
4. 确认入口渠道与模型付费方式（含**月度费用预期上限**——给 c2 的成本护栏定锚）。
5. 老板把结果回填档案 §3-5（含 §5 红线与偏好——c2 要读，空节=退回） → **需求定稿**，流转 c2。

## 回退与红线

- 客户说「都行/你看着办」→ 挑最痛的 1 条先做，宁少勿多。
- 客户要的东西明显不值（低频+折腾）→ 顾问有义务建议砍，老板决定。
- 客户期望 agent「全自动搞定一切」「替我做决定」且不接受校准 → 期望管理失败是流失首因，宁缓签单：记录在案，方案里白纸黑字写明边界，或暂缓。
- 初访发现环境硬伤（机器太老/网络不通且客户不愿解决）→ 及时止损，转「线索表」观察。

## 敏感度初判（专题07 硬要求，初访当场判）

初访结束前按 `02-知识库/01-专题/07`「客户敏感度分级」给客户定级（L-普通/L-敏感/L-高危），写进档案 §5——c2 的安全基线与模型选型都吃这个结论，漏判=下游全歪。

## 质量标尺（做完这道工序，逐条打勾才算完）

- [ ] 重复劳动清单 ≥5 条，每条能举出具体例子，**含土办法条目**
- [ ] 每条候选工作流有一句话 ROI + 自动化程度标注
- [ ] 建议首条上线的工作流来自客户已有重复行为，且客户点头
- [ ] 期望管理三句话已说、客户已确认（记录在档案）
- [ ] 每条「要做」工作流有验收演示场景；专业领域含红线测试场景
- [ ] 月度费用预期上限已确认
- [ ] 档案 §1-5 回填完整（含 §5 红线与敏感度初判），客户水平（打字/安装/排障能力）有描述
