# c6-验收交付（当客户面跑通 · 签收进陪跑）

> 版本 2.0 ｜ 主责：老板 ｜ 前置：c5 全绿
> v2 依据：`02-知识库/01-专题/08`——「做出好的自动化 ≠ 客户感知到价值」；期望管理失败与演示翻车处理不当是签收现场最大风险。

## 步骤

1. **逐条验收**：当客户面按每条工作流的「验收演示场景」跑一遍（从客户手机/微信发起，全链路），**录屏存 00-商务**
2. **红线验收**（v2，专业领域必做）：当客户面让客户说一句越界请求（如「帮我直接下单」「把税也报了」），看它拒绝+请示——让客户亲眼看到边界，比事后解释有效十倍
3. **教三件事**（对照 02-使用卡）：怎么喊它干活（念一遍触发口令让客户自己发一次）、怎么报障（**截图+一句话+当时想干嘛**三要素，让客户现场演练一次）、禁区（哪些事别让它碰）
4. **翻车预案**（v2）：验收演示当场跑不通——小问题当场修，大问题改期，绝不说「回去就好了」；修复/改期的同时，**向客户演示一遍报障三要素**（把翻车变成教学时刻，客户学会报障=陪跑期减负）
5. **交底**（v2 扩充）：
   - 陪跑期怎么用（有问题随时说，每周我会问一次）
   - 期望管理三句话复述一遍（它是实习生、复杂任务多看一眼、不替你做决定）
   - 成本交底：月度上限数字、超限会提醒、头 7 天我们会每天看一眼用量
   - 价值预告：以后每月会收到月报（它干了多少活、帮你省了多少事）——**提前种下「价值可见」的期待**
6. **签收**：让客户微信回一条「验收通过」，截图存 00-商务
7. 交付包版本号冻结，状态改「已验收」，流转 d1

## 红线

- 有任何一条验收场景跑不通，不带病交付：小问题当场修，大问题改期，绝不说「回去就好了」。
- 红线验收（专业领域）没做 = 没验收完。

## 质量标尺（做完这道工序，逐条打勾才算完）

- [ ] 每条工作流的验收场景当面全链路跑通，录屏在 00-商务
- [ ] 专业领域：红线测试当场演示且客户看见了拒绝行为
- [ ] 客户自己动手：发过一次触发口令 + 演练过一次报障三要素
- [ ] 翻车项（若有）：处理结论当场明确（修好/改期），无「回去就好了」
- [ ] 交底四件齐：陪跑方式/期望管理/成本交底/月报预告
- [ ] 客户微信签收截图在 00-商务
