# i18n 术语表 · 中英定名统一

> 版本 1.0 ｜ 2026-09-18 夜航建立 ｜ 全仓生效：中英 README、案例库、配方库、贡献翻译一律从表。
> 原则：定名一旦写入本表，各语言文档不得各翻各的；新增术语先入表再使用。

## 核心概念

| 中文（正宫） | English | 日本語 | 定义备注 |
|---|---|---|---|
| AI 落地顾问 | AI Landing Consultant | AI導入コンサルタント（统一此定名；「ランディング・コンサルタント」废弃） | 项目名。指「帮部署者给最终用户部署专属 agent」的角色与本项目 |
| 部署者 | deployer | 導入者 | 购买/开展落地服务的人（老板或自由顾问） |
| 最终用户 | end user | エンドユーザー | 完全不懂技术的真人（拉面店老板、小会计……） |
| 落地 | landing / go-live | 定着・運用開始 | 不译「implementation」——我们卖的是「用起来」，不是「装完」 |
| 交付包 | delivery package | 納品パッケージ | c3 产出的整套自装配指令集 |
| 自装配 | self-assembly | セルフアセンブル | 空白 agent 读包自己装配自己。**不译 auto-setup**（那是安装器的活） |
| 自装配指令 | self-assembly instructions | セルフアセンブル指示書 | `00-自装配指令.md`，交付包的心脏 |
| 陪跑 | companion service / retainer | 伴走サポート | d1-d5 持续服务线。「retainer」用于商务场合 |
| 进化守则 | evolution rules | 進化ルール | 客户 agent 的自我进化护栏，随包交付 |
| 心跳工作流 | heartbeat workflow | ハートビートワークフロー | 每天报平安的工作流；失联即警报 |
| 六要素 | six elements | 六要素 | 触发/输入输出/分步/兜底/验收/版本头 |
| 质量标尺 | acceptance checklist | 品質チェックリスト | 每道 SOP 末尾的勾选项 |
