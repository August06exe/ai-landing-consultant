为什么是它

隐私主权

数据不出门

自托管：agent 跑在客户自己电脑上，聊天记录、业务数据永不上传第三方。开源的是产线，不是客户档案。

可复制交付

11 道标准工序

访谈、方案、交付包、部署、验收、陪跑——每道工序带质量标尺。服务可以被复制，而不是每次靠灵感。

自装配范式

空白 agent 自己装自己

交付包不是文档，是施工图：部署只做到「agent 活了+模型通了」，它自己按包内指令装配成人格、工作流、定时任务。
