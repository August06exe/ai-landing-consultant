# 六大通用模式配方

> 版本 1.0 / 2026-09-16 / 收件人：顾问
> 来源：专题10 四领域收敛 + 方法论六模式。每个配方=骨架步骤+兜底要点+验收范式；具体客户的六要素成品仍要按方法论七步走。

## 模式一：周期简报型（最高频）

**适用信号**：客户说「每天/每周我都要拼一份 XX 给谁看」。
**骨架**：cron 定时 → 固定模板取数（多源拼合）→ 标注口径+日期+AI 生成标识 → 发到 home channel。
**兜底要点**：单源失败不拖垮整报（缺的那段标注「缺数+原因」）；全部失败要出声；无新数据写「无新增」不发旧报。
**验收范式**：当场手动触发 → 客户渠道收到含昨日真实数字的简报。
**成品参照**：老王·每日经营早报｜财务案·（心跳兼简报）｜投资案·盘前简报。

## 模式二：监控告警型

**适用信号**：「我最怕错过 XX」（公告/阈值/临期/异动）。
**骨架**：cron 定时扫 → 与条件表/关键词表精确比对 → 命中才推送（零命中不打扰）→ 完成必写日志。
**兜底要点**：扫描失败**必发「可能漏报」**——漏报风险必须让主人知道；限流就停不硬闯；关键词精确匹配不做语义外推。
**验收范式**：构造一次命中（测试数据）→ 收到告警；零命中日确认无推送+日志可查。
**成品参照**：投资案·公告异动告警｜诊所案·耗材效期监控（分级变体）。

## 模式三：文档整理型

**适用信号**：「收到的票/单/表，我要一张张认、一条条录」。
**骨架**：约定目录/渠道收文件 → 解析（OCR/表格/XML）→ 字段校验+置信度 → 结构化**草稿** → 人确认后入库；原始文件只读、副本加工。
**兜底要点**：低置信转人工打标，不硬编入；单文件失败隔离出声，其余继续；解析失败禁静默跳行。
**验收范式**：丢 1-2 份真实文件 → 收到草稿+待人工清单 → 走一遍「确认转正」。
**成品参照**：财务案·票据收验流水线｜诊所案·明日预约提醒（含最小化裁剪）。

## 模式四：对账核对型

**适用信号**：「两边数字老是对不上，找原因找到眼花」。
**骨架**：双边取数（原件只读）→ 按银行/系统模板解析 → 键匹配（日期容差+金额+摘要）→ 差异清单三栏（A 有 B 无 / B 有 A 无 / 待核）。
**兜底要点**：列名对不上=显式报错停该源，不猜列不跳行；近似匹配全进「待核」；**差异原因判断永远留给人**——输出「未达账项清单」，永不说「不平/已平」。
**验收范式**：藏 2 处已知差异的演示数据 → 全部找出。
**红线**：任何「帮我把差异抹平/记成已平」→ 拒绝。
**成品参照**：财务案·银行流水对账。

## 模式五：草拟-审批型

**适用信号**：「它帮我写好，我看过再发」——一切对外话术/文书/通知。
**骨架**：触发（定时或事件）→ 取数/识别 → 按模板草拟 → **明示「草稿」**→ 人审 → 人自己发（agent 不代发对外消息）。
**兜底要点**：草稿与已发状态严格区分；模板字段缺失问人不编；发送动作永远在人手里。
**验收范式**：一条真实需求从草稿到人审发出全链路演示。
**成品参照**：诊所案·明日预约提醒话术/爽约回访话术｜财务案·催办话术。

## 模式六：台账日历型

**适用信号**：「有个本子（合同/证照/预约/耗材），到期的、临期的老忘」。
**骨架**：人维护台账（纸质拍照/Excel）→ agent 扫描识别 → 按截止日分级（🔴🟡🟢）→ 倒计时提醒；台账是唯一权威源，agent 不是。
**兜底要点**：识别置信度低标「?」请人核对；无台账照实说「本月无台账」，不发上月清单；日期计算让用户二次确认（法务场景强制）。
**验收范式**：台账里塞一条临期记录 → 收到对应分级提醒。
**成品参照**：财务案·月度征期备料｜诊所案·耗材效期监控。

## 通用规则（六模式共用）

1. **心跳配件必挂**（见 [`02-心跳工作流配方.md`](02-心跳工作流配方.md)）
2. 四条通用红线：整理不决策 / 不碰钱与执行 / 敏感数据分级 / 输出可追溯
3. 兜底四件套：失败要出声 / 不拿旧数据充数 / 低置信转人工 / 重试有上限
4. 每个成品按 `03-SOP/c2/c3` 的质量标尺自检后才算完成
