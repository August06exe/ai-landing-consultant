# wf-周回复复盘 ｜ 满满轻食版（示例）

> 版本 1.0 / 2026-09-20 / 收件人：客户的Hermes

## 1. 触发方式

- 定时：`0 20 * * 0`（周日 20:00；执行体：cron 调起）
- 口令：「本周复盘」

## 2. 输入 → 输出（例子）

- 输入：`已处理清单.txt` + 本周投喂评价的汇总（执行体：agent 从本周处理记录统计）
- 输出（微信私聊）：
  > 📊 本周评价复盘（10/6-10/12）
  > 共 96 条：好评 85 ｜ 🟢6 ｜ 🟡4 ｜ 🔴1（已转你）
  > 回复率：🟡🟢 10/10=100% ✅（上周六成）
  > 差评关键词 Top3：洒漏×3 ｜ 送错×1 ｜ 态度×0
  > 被点名最多：低卡牛肉碗（3 次，均为「包装洒」）
  > 一句话：洒漏是主因，建议看出餐打包环节——要不要我把 3 条原文发你？

## 3. 分步 SOP

1. 统计本周各星级/级别数量与回复率（执行体：agent 汇总已处理清单）
2. 差评关键词聚类 Top3（执行体：agent 归类；不解读成「原因」，只陈列频次）
3. 一句话观察 + 可选的「要不要看原文」——**建议只到工序层面（打包/配送/出餐），不给经营结论**（整理不决策）
4. 发送（执行体：gateway 推送）

## 4. 失败兜底

- 本周零差评 → 发「本周零 🟡🟢，复盘无对象」（好事也出声）
- 统计源文件缺失 → 显式报「统计失败：已处理清单损坏」，不编数字

## 5. 验收演示场景

现场用测试数据跑一遍：数字对得上、关键词 Top3 有频次、建议不超过工序层面——三项全中即过。
