# 示例：老周果蔬·征期提醒官（虚构完整案例）

> ⚠️ 人物与数据全部虚构。这是 **L1 纯部署**的最小案例——给「第二单」练手用：一条工作流、一个数据文件、半天交付。两个看点：**只提醒不代办**（税务红线的极致克制）与**政策类数据的更新兜底**（征期表会过时，谁来看住它）。

**客户**：老周（周建国），社区果蔬店，个体户经营 6 年。痛点原话：「记账报税的事我完全不懂，听说个体户也要报税，罚过一次 200 块，就怕再忘」；「问过代账，一年 2400，我一个月流水才三万」。
**服务包**：L1 纯部署（1 条示范工作流+1 页使用卡，与 04-运营/服务标准.md §1 口径一致；不含定制工作流设计）。渠道=微信私聊；模型=DeepSeek（国内直连，月成本 <5 元）。
**一条工作流**：征期提醒（增值税/经营个税征期节点提醒+零申报自查提示）。

**为什么这条工作流成立**：征期日历是**公开、稳定、可枚举**的信息（税务局每年发布），agent 每月照表提醒即可；老周本来就要「记着别忘」——这条工作流只是把「记」外包出去。**不碰申报动作**（那是代账的地盘，也是红线）。
