# 示例：安宁口腔诊所（虚构完整案例）

> ⚠️ 人物与数据全部虚构。这是「医疗=敏感级」客户按 c1-c6 走完一遍的样子——两个看点：**冷启动纪律**与**数据最小化**。

**客户**：刘建国医生（所长）+前台赵淑芬+2 名护士。每天 20-30 个预约，纸质预约本+微信手动逐个提醒；每月爽约 8-10 单，耗材效期全凭人脑。
**服务包**：L1+服务包（轻量）。渠道=微信私聊；模型=本地部署（Ollama），**数据不出机**（专题07 L-敏感）。
**四条工作流**：每日晨间汇报（心跳）/ 明日预约提醒 / 爽约回访清单 / 耗材效期监控。

**与拉面店案例的两处不同**：
1. 第一条上线的是淑芬**本来就在做**的「下午翻本子列名单」，不是最「聪明」的场景（冷启动纪律）
2. 所有输出只见「姓氏+手机尾号」，全名与完整号码不进任何输出（数据最小化）
