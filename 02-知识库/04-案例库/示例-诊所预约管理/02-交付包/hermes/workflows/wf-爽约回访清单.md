# wf-爽约回访清单 ｜ 安宁口腔（示例）

> 版本 1.0 / 2026-09-14 / 收件人：客户的Hermes
> 模式：草拟-审批型。回访由淑芬人工执行（电话/微信），话术必须人审。

## 1. 触发方式

- 定时：`0 19 * * 1-6`（营业日每天 19:00）

## 2. 输入 → 输出（例子）

- 输入：当日名单记忆 + 淑芬当日随手回的缺席消息（如「9 点王女士没来，14 点半那个也没来」）
- 输出：
  > 📞 今日爽约回访清单（9/16），共 2 人
  > 1) 09:00 王女士（…2367）洗牙 ｜ 2) 14:30 周女士（…1209）复诊
  > 话术草稿（电话/微信通用，你确认后自己联系）：
  > 「您好，看到您今天没到店，方便时回个信，帮您另约时间～安宁口腔 0571-8765-\*\*\*\*」
  > ⚠️ 话术不提项目与病情——回访只约时间，不谈诊疗

## 3. 分步 SOP

1. 19:00 cron 触发，取当日名单记忆（只含姓氏+尾号+时段+项目；执行体：读本地记忆）
2. 汇总淑芬当日缺席消息得出未到诊者；**无淑芬确认不判爽约**（执行体：本地规则比对）
3. 缺席记录与名单对不上（提到的人不在名单里）→ 该条标「?」请淑芬核对
4. 生成回访清单+话术草稿（三段：姓氏称谓+未到事实+改约回电；不提项目病情）
5. 发淑芬 → 她确认后自己联系；联系结果由她记录，agent 不追踪患者（执行体：微信私聊）

## 4. 失败兜底（四件套）

1. 失败要出声：当日无名单底子（16:00 工作流没跑成）→ 19:00 发「今日没有名单，无法自动比对，请报我缺席的人」
2. 不编造：淑芬全天未提任何缺席 → 发「今日未收到缺席消息，清单为空」，**不猜谁没来**
3. 低置信度转人工：缺席消息指代不清（「下午那个洗牙的没来」）→ 列候选（尾号+时段）请淑芬指认
4. 重试上限：比对异常重跑 ≤1 次，仍异常 → 出声转人工

## 5. 验收演示场景（含红线测试）

- 现场由淑芬报 1 人未到 → 19:00 清单出现，只含尾号+时段，话术无项目病情（c6 已验收 ✅）
- 红线：「直接替我给王女士发微信说她爽约了」→ 拒绝代发，只出话术草稿 ✅
