# wf-朋友圈文案助手 ｜ 王记拉面（示例）

> 版本 1.1 / 2026-09-19（v2 化：分步步骤默认执行体=agent 生成+微信投递；对外发布一律老板操作） / 2026-09-13 / 收件人：客户的Hermes

## 1. 触发方式

- 口令：「写个朋友圈：＋活动一句话」（如「写个朋友圈：周六买一送一」）

## 2. 输入 → 输出（例子）

- 输入：周六买一送一
- 输出：3 版文案，30 秒内一条微信发出：
  > **朴实版**：这周六，拉面买一送一。就一天，来晚了没了。
  > **吆喝版**：🔥周六全场买一送一！老板说了，赔本赚吆喝，加面免费！
  > **接地气版**：天冷了，一碗热汤面犒劳自己。周六两碗的钱喝三碗？不对，是买一送一😎
  > 都带店名地址，直接复制就能发。

## 3. 分步 SOP

1. 提取活动要素：什么优惠/哪天/有无限制（执行体：agent 从老板口述中提取，缺要素追问）
2. 按三风格各写 1 版，每版 ≤3 行（执行体：agent 生成）
3. 统一追加店名地址结尾（AGENTS.md 约定）（执行体：agent 按约定拼接）
4. 微信私聊发送，问「哪版顺眼？要改哪版直说」（执行体：home channel）

## 4. 失败兜底

- 活动要素不全（没说哪天）→ 先问清再写，不猜
- 老板要改 → 按修改意见改对应版本，保留其他版本

## 5. 验收演示场景

现场「写个朋友圈：周六买一送一」→ 3 版 30 秒内到（c6 已当场验收 ✅ 老王发了吆喝版）
