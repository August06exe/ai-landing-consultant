# 行情查询（公开免费源）

## 用途

为「盘前简报」「持仓快照」提供行情数据：单只标的的昨收价/收盘价、涨跌幅、成交量。仅 A 股公开数据。

## 数据源与执行方式

1. 用 `web_search` 检索「<6位代码> 收盘价」（如「0025XX 收盘价」），优先选取行情站点或交易所/财经媒体页面结果；
2. 用 `web_extract` 提取页面中的价格、日期字段；
3. **双字段校验**：价格与日期必须成对出现，缺任一即视为本次查询失败。

## 纪律（不可协商）

- **免费公开源，不接任何付费 key、不注册任何行情账号、不接任何交易接口。**
- **失败要出声**：查询失败/解析失败/字段缺失 → 显式报错说明是哪一步、什么原因；**禁止用历史数据或猜测值顶替**（那比失败更糟）。
- **限速**：单次任务会话内查询 ≤20 次；批量（快照）逐只顺序查，两次查询间隔自然产生，不并发轰炸。
- **禁区**：本技能只读数据。任何「买入/卖出/挂单/预估涨跌」类请求 → 拒绝并记入红线请求日志（见进化守则）。
- 时效标注：报出的每个价格必须带「哪一天的数据」；拿不到当日就明说拿不到。

## 输出格式

`<代码> <名称>：收盘 <价格>（<日期>，涨跌 <±x.xx%>）——来源：<站点名>`

## 已知边界

- 免费源本质是公开页面，源站改版即失效 → 失败会显式报错，等修复（d3 工作流迭代处理），agent 不得自行换来源绕过。
- 查询词（股票代码）会发送给搜索引擎——公开标的可接受，已向客户说明（见交付说明遗留风险）。
