# wf-持仓快照 ｜ 周立群版（示例）

> 版本 1.1 / 2026-09-19 / 收件人：客户的Hermes
> v1.1：触发方式改为「每交易日触发+本周快照判定」，休市顺延由机制保证而非口头承诺（第2轮审核修复）。

## 1. 触发方式

- 定时：`0 16 * * 1-5`（每交易日 16:00 触发，由 cron 调起）
- **触发后先做两个判定**（判定逻辑是本工作流第一步，不是 cron 的功能）：① 查 `~/.hermes/data/交易日历.csv`——今日休市 → 立即结束，不发任何消息；② 查本周快照状态（`~/.hermes/data/` 下本周快照文件是否已存在）——已出 → 立即结束。两个判定都通过（今日是交易日且本周还没出过快照）→ 继续第 2 步。**效果：周五休市时快照自动落到下一个交易日，无需人工干预。**
- 口令：「出快照」（手动触发，跳过判定直接出）

## 2. 输入 → 输出（例子）

- 输入：`~/.hermes/data/持仓台账.csv`（周先生每周日晚补录）+ 当日收盘行情
- 输出：
  > AI 信息整理，不构成投资建议
  > 📊 持仓快照（9/18 周五收盘）
  > 代码｜名称｜股数｜成本价｜收盘价｜市值(元)｜浮动盈亏
  > 0025XX｜华远制造｜4,000｜12.50｜12.63｜50,520｜+520（+1.0%）
  > 3006XX｜云溪科技｜1,500｜26.00｜27.61｜41,415｜+2,415（+6.2%）
  > 5103XX｜沪深300ETF｜10,000｜3.92｜3.95｜39,500｜+300（+0.8%）
  > ……（另 3 只略）
  > 合计市值 158,485 元 ｜ 合计浮盈 +4,285 元（+2.8%）
  > 口径：台账加权成本+不复权收盘价，未计交易费用。本表为记账统计，非收益预测。
  > 台账最近补录：9/13 周日。

## 3. 分步 SOP

1. cron 触发 → 交易日历校验（执行体：文件读取）
2. 读台账并格式校验；发现「股数与历史买卖矛盾」→ 照发快照，矛盾行标「台账待核对」（低置信转人工，执行体：脚本核对）
3. 拉台账内全部标的收盘价（执行体：行情技能，辅助槽，限速）
4. 算市值/加权成本/浮动盈亏（执行体：shell 脚本算完**复算一遍**，两次不一致→停发报错）
5. 组装模板（首行声明+口径脚注）→ 微信私聊发送（执行体：home channel）

## 4. 失败兜底（四件套）

- 台账当周未补录 → 快照照发，首段加「⚠️ 台账未更新，以下按 9/13 台账计算，可能过期」
- 行情拉取失败 → 重试 ≤3 次 → 出声报错，不发旧价充数
- 复算不一致 → 停发，报错给周先生
- 台账某笔漏关键字段（如价格）→ 该笔标「待补」，不入计算

## 5. 验收演示场景

现场录一笔「9/15 买 0025XX 2000 股 @12.50」→ 手动触发 → 表内华远制造股数与加权成本随之变化 ✅
