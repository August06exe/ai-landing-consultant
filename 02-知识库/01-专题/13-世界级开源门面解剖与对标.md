## 三、装逼弹药包（对外口径，全部真实可查）

### 3.1 定位金句（中英各 3 条，按场合）

**中文**：
1. 「客户的数据只住在客户电脑里——开源的是产线，不是客户档案。」（首屏主权句，改自 zeroclaw 式主权主张，2026-09-16 专题09 已备案）
2. 「别人交付文档，我们交付一台会自己装配自己的 agent。」（自装配范式一句话）
3. 「11 道工序，每道带验收标尺——服务可以被复制，而不是每次靠灵感。」（卖给想开展服务的部署者）

**English**：
1. "Your client's data never leaves their machine. We open-source the production line — never the client files."
2. "We don't deliver documents. We deliver an agent that assembles itself."（自装配）
3. "Eleven standard operating procedures, each with acceptance checklists — consulting that replicates."（方法论可复制）

### 3.2 差异化一句话（市场空位声明）

> **「落地顾问方法论的开源化」在市场上没有第二家：agent 框架管「agent 怎么跑」，awesome 清单管「技能有什么」，我们管「一个不懂技术的人怎么真正用起来」——领域合规红线前置、交付包自装配、11 道工序陪跑，三件事合成一个仓库。」**

对标话术（对比锚点，公开场合可用）：
- vs ChatGPT 直接用：「ChatGPT 给你一篇文档就结束；我们交付一台 7×24 在客户聊天渠道里干活的 agent，带验收。」
- vs agent 框架（hermes/nanobot）：「框架回答『agent 能干什么』，我们回答『小白怎么用起来』——框架是引擎，我们是驾校。」
- vs awesome 清单：「技能清单解决『能干什么』（供给侧），我们解决『跟我有什么关系』（需求侧）——用例思维的交付级实现。」
