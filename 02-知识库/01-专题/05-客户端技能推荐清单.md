# 专题05：客户端技能推荐清单（按场景配装）

> 来源：官方 [Optional Skills Catalog](https://hermes-agent.nousresearch.com/docs/reference/optional-skills-catalog)（2026-09-16 抓取）、Bundled Skills Catalog、[awesome-hermes-skills](https://github.com/ZeroPointRepo/awesome-hermes-skills)（本地全文：`02-知识库/03-参考技能/awesome-hermes-skills-README.md`，81KB）。

## 安装/卸载命令

```bash
hermes skills install official/<分类>/<技能名>   # 官方可选技能，默认不激活
hermes skills uninstall <技能名>
hermes skills search <关键词>                     # Skills Hub（agentskills.io）搜索
```

另：Hermes 自带 40+ 内置技能并会**自己写新技能**（自进化）；技能有信任分级（trusted/built-in/community）。给客户装第三方技能前先看一眼 SKILL.md 内容——这是老板的交付责任。

## 按客户场景配装（少即是多，一次别超过 3-5 个）

| 客户场景 | 推荐技能（官方目录名） | 说明 |
|---|---|---|
| 信息简报/监控 | `devops/watchers`、`research/rss-feeds`、`research/blogwatcher` | RSS/JSON/GitHub 轮询+去重；配 cron 就是「每天早报」的原料 |
| 搜索与调研 | `research/duckduckgo-search`、`research/searxng-search` | 免 key 搜索，国内可用性需实测；`research/parallel-cli` 深度研究 |
| 网页抓取 | `research/scrapling` | 隐身浏览+Cloudflare 绕过（**给客户用前评估合规**） |
| 办公文档 | `finance/excel-author`、`finance/pptx-author` | openpyxl/python-pptx 无头生成 Excel/PPT |
| 电商运营 | `productivity/shopify` | Shopify Admin/Storefront API |
| 自媒体 | `creative/social-media-content-calendar` | 多平台内容排期 |
| 语音 | `mlops/whisper` | 99语言语音转文字（微信语音消息场景） |
| 记忆增强 | `productivity/memento-flashcards`、`research/qmd` | 闪卡复习；本地笔记/文档混合检索 |
| 从 OpenClaw 搬家 | `migration/openclaw-migration` | **潜在客源**：把 OpenClaw 用户的记忆/技能迁进 Hermes 是一种服务 |
| 给小白的安装向导 | `devops/setup-wizard-generator` | 生成引导人类逐步操作的 bash 向导——**思路已借鉴进我们的部署方案写法** |
| 决策简报 | `communication/one-three-one-rule` | 1-3-1：问题+三个选项+一个推荐（已并入顾问提示词） |

## 配装纪律（写进每个交付包）

1. 技能跟着工作流走：每条工作流列出它依赖的技能，没工作流用的不装。
2. 每装一个，给客户一句话说明「它是干嘛的、怎么触发」。
3. 安全类（pentest/osint/godmode）、支付类技能**不主动**给小白客户。
4. 装完跑一遍验收演示，确认技能真的被触发（不是 Hermes 自己绕过去了）。
