# 官方文档（本地拉取）

本目录的 `llms-full.txt`（官方全量文档）不入 git（体积大且会过期），用脚本随时拉最新：

```bash
bash scripts/fetch-hermes-docs.sh
```

- `llms-full.txt`：全站文档合一（约 4.6MB）。**查法**：`grep -n "关键词"` 定位行号 → 按区间读。禁止整读。
- `docs-llms-index.txt`：分节链接索引。
- 来源：https://hermes-agent.nousresearch.com/docs/ （Nous Research，MIT 项目；文档版权归上游，本仓库只提供拉取脚本不分发内容）。
