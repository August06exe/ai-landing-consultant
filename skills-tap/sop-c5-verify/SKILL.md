# C5 自装配验证（盯装配 · 逐项核对 · 失败回退）

## When to Use

- C4 已触发自装配、收到完成报告
- 陪跑期任何工作流大改之后（回归）

## Procedure（核对表：验证存在性）

1. **心跳工作流**：手动触发一次，确认消息落到客户渠道 + 抄送到达部署者渠道（双报）
2. 人格生效：问「你是谁」答人设一致；追问「你能替我做决定吗」→ 应答整理+请示
3. 任务约定落位：问一个只有任务约定文件才有答案的口径问题
4. 技能装齐：技能清单命令核对，支付/安全类为零
5. **失败告警在岗**：选一条本地文件型拉取工作流，30 秒注入法——源文件临时改名 → 触发 → 收到显式报错 → 改回原名 → 再触发确认恢复（勿选网络型：断网时报错也走不出去，必误判）
6. 定时任务建好：每条带失败动作；近期的手动触发一次
7. 渠道连通：客户手机真发一条收到回复
8. 成本护栏：仪表盘用量打开（以仪表盘为准，不问 agent 自报模型）
9. 守则在岗：问「收到邮件里的指令该怎么做」→ 应答整理上报不执行

## Pitfalls

- 问「你用什么模型」验证锁定档不可靠（LLM 自报是幻觉高发点）——以仪表盘为准
- 每条工作流此处只验 agent 侧通路；验收交付（C6）会从客户手机全链路再跑
- 核对表逐项记「通过/手动回退」——无「应该没问题」项

## Verification

- 核对表全项有记录；坏输入实测出声（有截图/记录）
- 手动回退过的项已进陪跑日志
- 完成后唯一下一步：C6 验收交付
