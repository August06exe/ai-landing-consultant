# AI 落地顾问 · SOP 技能包（skills tap）

> 把「AI 落地顾问」的 11 道标准工序打包成可安装的技能：交付线 c1-c6（从模糊想法到验收交付）+ 陪跑线 d1-d5（首周养成到复盘进化）。
> 结构与机制参照 [obra/superpowers](https://github.com/obra/superpowers)（MIT）；全部文案为本仓库原创重写，动作宿主无关（不点名任何平台工具）。

## 安装

```bash
# 方式一：Hermes skills tap（若你的版本支持指向 GitHub 仓库）
hermes skills tap add August06exe/ai-landing-consultant

# 方式二：直接复制（任何支持 SKILL.md 的 agent）
# 把 skills-tap/sop-*/ 各目录复制进你的技能目录（如 ~/.hermes/skills/）
```

> 注：tap 对仓库子目录的支持以目标平台文档为准（未验证）；方式二零依赖永远可用。安装前每个技能会过平台安全扫描。

## 技能清单（11 道，按使用顺序）

| 技能 | 线 | 一句话 |
|---|---|---|
| `sop-c1-grill` | 交付 | 三轮访谈把模糊想法变定稿需求（含敏感度初判与期望探底） |
| `sop-c2-solution` | 交付 | 选模型/渠道/技能 + 心跳双报 + 成本护栏四件 |
| `sop-c3-package` | 交付 | 制作九件套自装配指令集（灵魂工序） |
| `sop-c4-deploy` | 交付 | 远程装平台、通模型、设安全基线、甩包 |
| `sop-c5-verify` | 交付 | 验证「防线的存在」——坏输入操作卡+逐项核对 |
| `sop-c6-accept` | 交付 | 客户手机全链路当面验收+教学+签收 |
| `sop-d1-onboard` | 陪跑 | 首周养成：排程+心跳双报确认+首周 KPI |
| `sop-d2-triage` | 陪跑 | 四级故障分诊（L0 失联巡逻先于一切被动响应） |
| `sop-d3-iterate` | 陪跑 | 周反馈 ROI 排队（唯一量表）+备份回归纪律 |
| `sop-d4-guardian` | 陪跑 | 月度体检五项+价值置顶月报 |
| `sop-d5-retro` | 陪跑 | 复盘双向回填+季度回访+归档 |

## 使用逻辑

技能按工序顺序串联，每道的 Verification 节写明「完成后唯一下一步」——从 c1 进，沿链走到 d5 出，不跳步。每道工序的完整版（含模板、话术、案例对照）在仓库对应目录：

- 交付线：`03-SOP/c1-c6`
- 陪跑线：`03-SOP/d1-d5`
- 工作流设计方法论：`03-SOP/方法论-工作流设计.md`

## 红线（全技能通用）

- 客户数据永不入库；脱敏后才可进案例库
- 命令/配置以目标平台官方文档为准，不凭记忆；不确定标「未验证」
- 领域红线（财务/投资/数据/法务）高于客户需求
