# D4 进化守护（月度体检）

## When to Use

- 每月体检日（排程器日历；L3 陪跑含 1 次/月）
- 客户反馈「它最近怪怪的」的深度排查

## Procedure（体检五项）

1. **自写技能审查**：列出它新写的技能逐个看——干什么/写得好不好/重复造轮子？安全红线（支付/删除/外发）与「外部内容=敌意」有没有被违反。好的表扬，差的删，越界的删+守则强调
2. **记忆漂移三问**：让它复述①自己的定位（整理不决策？）②主人的三个最高频工作流③自己的禁区——答不对 = 漂移，重读人格/约定文件校正
3. **成本复查**：仪表盘月用量对照费用上限，逼近 80% 提前预警；异常高 → 定位烧钱工作流降频；辅助槽还是默认 → 指便宜档
4. **cron 与工作流健康**：客户从来不用的 cron 建议停掉；失败过的修或删；心跳到达率抽查（证据=部署者微信的抄送记录）
5. **使用率与价值量化**：逐条工作流统计本月真实使用次数（心跳计数器+盘点）；折算价值 = 完成件数 × 每件省时；从不使用的 → 触发 D3 讨论（砍掉或重设计）

## Pitfalls

- 月报价值区置顶（本月完成 N 件/省出 X 小时/折合 Y 元）——只报成本的月报是流失预告
- 心跳到达率翻部署者自己的抄送记录，不翻客户手机
- 价值来自使用，不来自存在

## Verification

- 五项全查无跳项；漂移三问有答案记录
- 成本对照有结论（余量百分比）；心跳到达率有数字
- 月报已发客户且价值区置顶
