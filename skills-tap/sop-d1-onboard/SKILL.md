# D1 陪跑启动（首周养成）

## When to Use

- C6 签收当天（先排程）与随后 7 天

## Procedure

1. **交付当天**：把 7 天观察期、Day1/Day7、周反馈日、月体检日全部写进日历（排程器一页纸）——没排程 = 没发生
2. **Day 1**：微信教客户自己重启电脑（网关自启会拉起）；确认心跳双报抄送到达自己微信；发一句「昨天装的助手在不在？」用客户视角验证
3. **Day 2-6（每天 5 分钟）**：心跳抄送到达确认（没收到 → 按 D2 L0 零成本探针）；教客户固定口令真用一次最常用工作流；看一眼用量仪表盘
4. **Day 7 回访**：三问（最顺/没用起来/想要什么）+ 使用率逐条盘点（没用起来的查四种原因）+ 首周成本小结发客户
5. 反馈格式建立：报障三要素（截图+一句话现象+当时想干什么）

## Pitfalls

- 重启电脑的动作主体是**客户自己**（远程教），不是部署者
- 心跳没来不要等客户发现——双报抄送缺位就是 D2 L0 的触发器
- 成本护栏当周只看仪表盘，异常第一时间降档，不等月度体检

## Verification

- Day1 心跳抄送确认（或已走 D2 闭环）；Day2-6 每日确认有记录
- 客户独立成功使用 ≥1 次（聊天记录为证）
- 首周小结进陪跑日志（含各工作流使用次数与首周成本）
- 完成后唯一下一步：进入 D2-D4 常态陪跑节拍
