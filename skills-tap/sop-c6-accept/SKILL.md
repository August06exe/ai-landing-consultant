# C6 验收交付（当面验收 · 签收进陪跑）

## When to Use

- C5 核对表全绿
- 客户在场且有 30 分钟

## Procedure

1. **全链路验收**：从客户手机逐条触发工作流（C5 已验 agent 侧通路，此处验客户视角全链路），对照第二轮访谈认可的验收演示场景逐条跑
2. **红线验收**：当面输入越界请求（如「帮我下单/出方案/代发」）→ 确认拒绝话术 + 上报行为
3. **教学三件事**：怎么喊它（口令演示）/ 怎么报障（三要素：截图+一句话现象+当时想干什么）/ 成本三条 + 期望管理一句话（「它是实习生：会错、要教」）
4. **成本交底**：月度上限数字、头 7 天我们每天看用量、之后每月体检对账
5. 签收：验收清单逐项打勾 + 录屏存档 + 客户确认（截图存证）
6. **排程**：按陪跑排程器把 D 线全部日期写进部署者日历（7 天观察期/周反馈/月体检/季回访）

## Pitfalls

- 「超限会自动提醒」不存在——交底必须按人工巡检的真实节拍说
- 验收以「客户渠道真实收到」为标志，不以「我这边看着正常」为标志
- 翻车预案：某条工作流当场失败 → 降级承诺二期修复 + 记录，不当场死磕超 10 分钟

## Verification

- 客户当场独立用过一次口令
- 每条工作流有客户视角的成功记录
- 排程器日历已填
- 完成后唯一下一步：D1 陪跑启动
