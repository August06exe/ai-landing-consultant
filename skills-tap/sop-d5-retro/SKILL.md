# D5 复盘与自进化（双向回填 · 季度回访）

## When to Use

- L3 陪跑期满 / L1-L2 交付后约定复盘点
- 季度回访日到达

## Procedure

1. **复盘会**：三方视角各一条——客户（最有用/最没用/没想到的）、部署者（耗时 vs 报价、哪个环节卡）、顾问（SOP 哪里不顺）
2. **可复用沉淀**：这一单的新工作流/话术/检查项 → 脱敏后按九件套回填模板或案例库
3. **回填执行边界**：单条回填（改一份文件+升版本）本会话直接做；批量修订（≥3 文件或动模板骨架）→ 回产线主会话做
4. **迁移预案**：确认换机 runbook 在配方库中可用；客户留存备份提醒在跑
5. **季度回访**：日历排入；回访三问（还在用吗/有什么想改的/身边有人要装吗——转介绍顺带问）
6. **结案归档**：客户夹整体移入归档区（夹名不变，只进不出）

## Pitfalls

- 复盘产出「下次注意」这种空话无效——每条经验必须落到具体文件的具体修改
- 结案后客户 agent 按进化守则自治：季度回访是唯一主动触点，别断
- 归档 ≠ 删除；真实客户数据永不入库（脱敏后才能进公开案例库）

## Verification

- 复盘三方记录进 05-复盘
- 回填项每行有去向（改了哪个文件+版本号）
- 季度回访已排程
- 客户夹已归档（或续费转新陪跑周期）
