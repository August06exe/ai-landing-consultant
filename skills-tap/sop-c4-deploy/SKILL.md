# C4 部署引导（远程 · 通模型 · 甩包）

## When to Use

- 交付包九件套齐且审校通过
- 与客户约好时间（45-60 分钟），录屏知情同意已做

## Procedure

1. **环境快检**（2 分钟）：目标平台下载源与模型 API 可达性；杀软类型记录（已知墙位查部署专题）
2. **装平台**：官方安装包下一步到底（能免管理员则免）
3. **通第一个模型**：按方案接通，发一句测试话确认回应（截图存证）
4. **安全基线**：渠道白名单只客户本人；命令需审批模式；支付/安全类技能零安装；免审批开关（YOLO 类）确认关闭
5. **成本护栏就位**：当天能生效的两件——用量仪表盘打开给客户看 + 辅助槽降档；另两件随后生效（守则随包/巡检进排程器）
6. **甩包**：交付包放客户机固定位置
7. **触发自装配**：一句话指令——「读取交付包自装配指令，按指令执行，完成后给我完成报告」
8. 期间教使用卡三件事（怎么喊/报障三要素/成本三条+期望一句话）

## Pitfalls

- 装完命令不存在 = 没开新终端（PATH 对已开窗口不生效）
- 成本护栏第③件（守则约束）在自装配完成前不存在——别在步骤 5 打勾
- 10 分钟无解就改期，别硬耗；回退路径提前想好（手机热点/备用远程）

## Verification

- 录屏知情同意在案；环境快检有结论
- 第一个模型真实回应（截图）
- 白名单/审批模式/禁区三件 + 免审批开关关闭
- 自装配完成报告全绿，心跳工作流排第一已建
- 完成后唯一下一步：C5 自装配验证
